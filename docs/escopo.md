# Escopo do Projeto: Assistente de Atendimento com IA

## Problema
Uma loja online enfrenta dificuldades no atendimento aos clientes devido ao grande volume de perguntas repetitivas, principalmente sobre produtos, prazos de entrega, formas de pagamento e trocas. Isso pode gerar demora nas respostas, insatisfação dos clientes e sobrecarga da equipe de atendimento.

## Assistente de IA
O nosso assistente virtual utilizará inteligência artificial para responder automaticamente as dúvidas frequentes dos clientes, oferecendo um atendimento rápido, disponível 24h por dia. Ele responderá com base em uma base de conhecimento definida pela empresa, com informações sobre produtos, entregas, pagamentos e trocas. Quando não souber a resposta, ele avisará o cliente em vez de inventar informações, o que permite que os atendentes humanos se concentrem em situações mais complexas.

## Usuário
O usuário é o cliente de uma loja online, que quer tirar dúvidas sobre produtos, entregas, pagamentos e trocas para decidir uma compra ou resolver uma questão sem precisar esperar por um atendente.

## Histórias de usuário
- Como cliente, quero consultar informações e preços dos produtos, para decidir o que comprar.
- Como cliente, quero saber os prazos e as formas de entrega, para planejar quando vou receber meu pedido.
- Como cliente, quero conhecer as formas de pagamento aceitas, para escolher a que for melhor para mim.
- Como cliente, quero entender como funcionam as trocas e devoluções, para comprar com mais segurança.
- Como cliente, quero ser avisado quando o assistente não souber responder, para não receber uma informação errada e saber que preciso falar com um atendente.

## Fora do escopo
- Consultar o estoque em tempo real, porque o assistente só lê a base de conhecimento e não acessa o sistema da loja.
- Consultar o status ou o rastreamento de pedidos, pelo mesmo motivo.
- Finalizar compras ou processar pagamentos.
- Transferir a conversa para um atendente humano: o assistente apenas avisa o cliente de que precisa falar com um.
- Usar dados reais de clientes ou de uma loja real: o projeto usa só dados fictícios.
